One job. Your crew. You watch.

      
The window above is one example, and those names are ones we picked. Add as many agents as you want and call them whatever fits. One can hand out the pieces. The others take a file each. If they share one model, they take turns, and the row says who is waiting.

      

        

          
Each row is one worker

          
Editing a file means that worker has it open. Waiting for the model means the turn has not started.

        

        

          
The folder is the limit

          
They read and write only the project you opened. The diff sits under the editor. A command does not run until you allow it.

        

        

          
The model stays yours

          
A local model, or an API key you already have. Several agents can share one. They take turns, and the row says whose turn it is.

Local. Private. Yours.

      
The model can run on your machine, or at an API you choose. The files stay in the folder you open. Flint is the window.

      

        

          
Chats stay on this computer

          
There is no Flint account, and the folder is not uploaded. A web search goes to DuckDuckGo, or to Brave if you add a key. An update check asks GitHub whether a newer Flint exists. You can turn that check off.

        

        

          
Only the folder you choose

          
The agents can read and change that folder. The rest of the machine stays out of reach.

        

        

          
A crew you name yourself

          
Add the agents you want and call them whatever fits. One can lead. The others take a piece each, at the same time.

        

        

          
You keep the last word

          
A change waits until you keep it. A command does not run until you allow it.
