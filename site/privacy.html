Privacy policy

What stays here.

22 October 2026

Flint is a local coding studio. There is no Flint account, and there is no Flint server that stores your chats or your folder.

On this computer

The app writes its own files on the machine where you run it. That includes settings, the model addresses you add, agent names and instructions, chats, notes, and a record of the folder you open. Those files stay in the app’s data folder. They are not uploaded by Flint.

The agents can read and change only the folder you open. A command runs on that machine after you allow it, or after you choose to allow commands in that folder.

The model you connect

A reply is sent to the address you saved. That can be a server on your own network, Ollama on this PC, or an API you typed in. The request can include the prompt, the open file, and the result of a tool. Flint does not operate that model. If the address belongs to someone else, their privacy policy covers what they do with the request.

Search

If an agent searches the web, the query goes to DuckDuckGo. If you add a Brave key in settings, the query and that key go to Brave instead. The key is stored in the local settings file. Search does not run unless the agent uses it.

Update check

When update checks are on, the app asks GitHub whether a newer release of kolan51/flint exists. GitHub sees that connection. The check does not include your chats or the files in your folder. You can turn the check off in Settings.

This website

This site is a static page. It does not create a Flint account, it does not set its own cookies, and it does not run analytics. When the home page loads, it asks GitHub’s API for the latest release so the download button can point at an installer. If that request fails, the Windows button uses the installer file next to the page. macOS and Linux buttons stay inactive until a build for them is published.

What Flint does not do

  • It does not sell personal information.
  • It does not build an advertising profile.
  • It does not require an account to use the app.

Contact

Questions about this policy go to the project on GitHub: kolan51/flint. The general terms sit beside this page.
